# 快速开始

## 安装依赖

``` bash
npm install
```

## 配置 API Key

以下两种方式任选其一：

-   **接入测试密钥**：启动后点击右上角接入弹窗中的 **"接入测试密钥"** 按钮，无需手动填写。
-   **自定义 Key**：编辑项目根目录 `.env`，写入你自己的密钥：

    ``` env
    DEEPSEEK_API_KEY=sk-你的密钥
    ```

    也可以直接启动后，在网页右上角的接入弹窗中粘贴 Key，后端本地保存、立即生效，无需重启。

> 提示：完整能力在接入大模型后解锁；未接入时系统会以本地模式提供基础陪伴，不影响上手体验。

## 启动

``` bash
npm start
```

访问：

``` text
http://localhost:3000
```

# 项目简介

**小知** 是一个面向学生自主学习场景设计的 Education AI Agent。

项目围绕学习全过程构建智能服务体系，使 AI 不仅能够回答问题，还能够理解学习状态、规划学习任务、执行教学服务、分析学习结果，并根据反馈持续调整学习路径。

核心闭环：

``` text
学习状态感知
        ↓
学习需求理解
        ↓
学习任务规划
        ↓
教学任务执行
        ↓
学习效果评价
        ↓
学习状态更新
        ↓
学习路径调整
```

# 智能出题与学习闭环

小知内置 **LLM 意图路由**，由大模型判断用户当前是想"继续聊天"还是"开始做题"：

```text
用户输入
   ↓
意图路由（LLM 判断）
   ├── chat     正常对话 / 知识讲解
   ├── clarify  想出题但信息不足 → 追问补全
   └── quiz     信息充分 → 生成交互题卡
                  ↓
              判分 / 错题收集
                  ↓
               AI 错因分析
                  ↓
            生成复习方案 / 时间表
```

-   对话框内自然输入"给我出几道题""考考我"即可触发交互题卡。
-   出题判断依赖**模型语义**而非关键词正则，只在出题意图明确且学科、知识点可确定时触发，避免误出题；信息不足时先追问。
-   每道题支持选项作答、即时判分与解析；错题自动归档。

答题完成后，依据**真实错题**生成 AI 错因分析，提供多套复习方案，并经诞生可执行的时间安排。

# Agent 能力模型

小知包含：

-   Perception：学习状态感知
-   Understanding：学习需求理解
-   Planning：任务规划
-   Memory：学习记忆
-   Action：任务执行
-   Evaluation：效果评价
-   Adjustment：路径调整

区别于普通聊天机器人，小知关注长期学习过程，而不是单次问答。

# 大语言模型接入

当前版本接入：

**DeepSeek 大语言模型接口**

用于：

-   自然语言理解
-   内容生成
-   多轮对话
-   解题推理

模型接口保持扩展能力，可根据需求替换其他兼容模型。

接入支持 **演示密钥一键接入** 与 **自定义 Key** 两种方式，互不影响；程序本地运行，Key 仅在本地配置文件。

# 数据可视化

内置**学习统计**与**数据大屏**两套视图：

- 学习统计：今日 / 本周学习时长、连续学习天数、目标完成度、学科投入分布。
- 数据大屏：学习趋势、90 天热力图、能力雷达、时段分布与智能洞察，支持演示数据与真实本地记录切换。
